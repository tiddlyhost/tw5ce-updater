# tw5ce-updater

Scripting to help upload empties from the [TiddlyWiki Community
Editions](https://github.com/CrossEye/TW5-CommunityEditions) repo to
[Tiddlyhost](https://tiddlyhost.com/).

The uploaded templates are visible
[here](https://tiddlyhost.com/explore/user/tw5-ce?t=1).

Currently there is only one, the [Tidbits Community Recipe
Edition](https://github.com/CrossEye/TW5-CommunityEditions#tidbits--recipe-edition-v100),
but in future there may be others.
